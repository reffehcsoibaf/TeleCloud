TeleCloud

Uma unidade T: no Windows cujos arquivos ficam guardados no Telegram. No dia a dia é uma pasta comum do Explorer, com janelas feitas para quem usa leitor de tela.

Para Windows 10 ou 11. Gratuito, sem anúncios.

Esta página e as versões publicadas no GitHub do projeto são os canais oficiais. Cópias obtidas em outros lugares não são de responsabilidade do autor.

Leia antes de usar. Os arquivos vão para um grupo privado da sua conta do Telegram e não são cifrados por padrão. Usar o Telegram como armazenamento em massa fica numa zona cinzenta dos termos de uso dele. Só um computador por vez deve usar a mesma conta. O TeleCloud não é um produto oficial do Telegram.

Como instalar e usar

  1. Baixe o TeleCloud.exe e abra. Ele pergunta se deve instalar no seu perfil (sem precisar de administrador) e se deve iniciar com o Windows.
  2. O driver WinFsp, que cria a unidade, vem dentro do .exe. Se faltar, o TeleCloud oferece instalá-lo, e o Windows pede permissão de administrador.
  3. Na primeira vez, uma janela explica como criar as chaves da API em my.telegram.org, depois pede o telefone e o código do Telegram. Os campos são nativos e lidos pelo NVDA.
  4. A unidade T: aparece. O ícone perto do relógio mostra a fila de envios; Enter nele abre a unidade.

Para atualizar, abra o novo TeleCloud.exe baixado. Ele fecha a cópia aberta (esperando os envios pendentes), troca o programa instalado e abre a nova, sem perguntas e mantendo os seus dados.

O que ele faz

  • Uma pasta comumA unidade T: funciona com qualquer programa do Windows, sem aplicativo especial.
  • Gravar é rápidoO arquivo vai primeiro para o disco e sobe ao Telegram em segundo plano. Se o programa fechar no meio, retoma no próximo início.
  • Arquivos grandesDivididos em partes de 64 MB; ao abrir, só a parte lida é baixada.
  • Cache com limitePadrão de 5 GB, que você muda em Configurações, no menu do ícone da bandeja.
  • Índice no TelegramA árvore de pastas também fica guardada no grupo. Num computador novo, basta entrar com a mesma conta.
  • Feito para leitores de telaJanelas com controles nativos e menu da bandeja acessível por teclado.
